# PRVoice

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE.md)

**Аудиоплеер аудиокниг для Android со встроенным поиском и загрузкой книг из интернет-источников.**

PRVoice — форк [Voice](https://github.com/PaulWoitaschek/Voice) с надстройкой: помимо всего, что умеет базовый
плеер (закладки, sleep-timer, скорость воспроизведения, пропуск пауз, Android Auto, синхронизация), PRVoice
умеет искать аудиокниги на русских сайтах и торрент-трекерах и скачивать их прямо в библиотеку.

## Что добавлено к Voice

- 🔍 **Поиск книг по интернет-источникам** — единый экран поиска по подключённым источникам
  ([baza-knig.top](https://baza-knig.top), [rutor.info](https://rutor.info) и др.)
- ⬇️ **Менеджер загрузок** — прямое скачивание mp3 (HTTP) и торрентов (libtorrent4j, последовательная
  загрузка — можно слушать, пока книга докачивается)
- 📚 **Каталог загруженных книг** — скачанное автоматически попадает в библиотеку Voice
- 🧩 **Слой источников как подключаемые адаптеры** — архитектура готова к переезду на QuickJS-песочницу
  со скриптами-источниками (план M5)

## Сборка

```bash
./gradlew :app:assembleFreeDebug
```

Требуется JDK 17+; Android SDK подключается стандартно (`local.properties` или `ANDROID_HOME`).
